FAQ

What people usually ask before hiring me

Didn’t find your question? Ask me directly.

How much does it cost to build a system?

It depends on scope: screens, business rules, integrations and timeline. After a first call I send a written proposal with a fixed or staged price — no surprises along the way.

How long does it take?

A first usable version is usually ready in weeks. Larger projects are delivered module by module so you can start using them early.

Which technologies do you work with?

Day to day: C#, .NET 8, ASP.NET Core, SQL Server and Angular. I also build Flutter and React Native apps, Unity games and deploy on Azure.

Does my company own the code and data?

Yes. Repository, database, domain and cloud accounts belong to your company from day one.

Can you maintain an existing system?

Yes. I have experience with legacy .NET Framework, MVC and Razor systems. I review the code and suggest evolving it step by step or rewriting it.

Do you work with clients outside Brazil?

Yes. I work remotely, with video calls and follow-up over WhatsApp or email, in Portuguese or English.

How does support work after delivery?

Every project includes a follow-up period. After that you can hire ongoing development or on-demand support.

Do you work under contract?

Yes. Scope, timeline, price, code ownership and confidentiality are defined in writing before we start.
